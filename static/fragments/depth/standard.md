# Depth: standard

Target report length: about **12–25 PDF pages**. Default depth when the user
does not specify.

## Selection intensity

- Full required section set from the output contract.
- Method: enough to reproduce the mental model of the design/algorithm;
  include critical parameters and defaults with anchors.
- Figures/tables: **3–7** load-bearing items with full bilingual caption
  blocks and evidence supported / not supported.
- Evidence audit: baselines, metrics, hardware/software setting, main results,
  and key ablations.
- Limitations + likely reviewer objections: concrete and actionable.
- Reproduction checklist: steps, configs, data/code availability as stated.
- Terminology: cover terms used across selected sections.

## Balance

Prefer one clear pass over the argument rather than exhaustive section-by-section
commentary. If the paper is long, deepen the core contribution path and keep
peripheral sections as short anchored notes.
