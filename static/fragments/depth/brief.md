# Depth: brief

Target report length: about **6–10 PDF pages**. Preserve required evidence;
do not pad.

## Selection intensity

- Overview: ≤1 page Chinese.
- Problem + significance: short.
- Argument map: compact (bullet-like structure is fine if each item stays
  bilingual+anchored in the ledger).
- Method: only the mechanisms needed to understand the main claim.
- Figures/tables: **1–3** most load-bearing; skip decorative plots.
- Evidence audit: focus on the hero comparison and one major caveat.
- Contributions / limitations / reproduction: concise checklists.
- Terminology: only recurring terms that appear in the selected items.

## Hard rules still apply

Bilingual fields, anchors, evidence-layer labels, and (if repo present) statused
code mappings remain mandatory for whatever is selected. Brevity never excuses
invented numbers or missing anchors.

## Cut order when over budget

1. Extra background and related-work narrative.
2. Secondary ablations.
3. Extended reviewer speculation.
4. Never cut anchors or bilingual fields from remaining items.
